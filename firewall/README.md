# Firewall

This project configures the `ufw` firewall on web-01 to block all incoming traffic except SSH (22), HTTP (80) and HTTPS (443).

## Files

| File | Description |
|------|-------------|
| `0-block_all_incoming_traffic_but` | The `ufw` commands used to block all incoming traffic except TCP ports 22, 80 and 443 |
